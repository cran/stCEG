# stCEG 0.1.0

* Initial release of **stCEG**, an R package for building, editing, and visualizing spatio-temporal Chain Event Graphs (CEGs).
* Includes support for asymmetric event trees, prior specification, and interactive visualizations with `visNetwork`.
* Provides a Shiny app interface for user-friendly exploration and customization of CEGs.

# stCEG 1.1.0

## Major changes

* Reworked CEG model summary methods.

* Added path probability calculations.
* Improved prior specification workflow.
* Improved plotting and Shiny application functionality.
* Updated documentation and examples.
